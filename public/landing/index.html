Teach by dragging, not prompting

Drag a note onto New cluster, then drop a second note beside it.

The agent names the theme and pulls every matching note in from across the board.

One action layer for you and the agent

A drag on the board and an agent tool call run the same move-notes action, with the same checks. Stigi is built on the Agent-Native framework: shared actions, shared data and shared app state.

Affinity sorting without the afternoon

Product teams sort feedback by hand with sticky notes and spreadsheets, and by the time the themes are named they are out of date. Stigi keeps the board live: correct one grouping and the rest follows.

Questions about Stigi

What data does the demo use?

Every board starts empty. One click loads 200 synthetic sample comments for a fictional expenses app, labelled in the app. You can also import your own CSV.

Which model sorts the notes?

Claude Sonnet 5.5 through OpenRouter, inside the Agent-Native agent chat. The agent changes the board only through Stigi's actions.

Does the agent learn my preferences?

Your drags steer the board you are working on. Stigi does not train a model or carry corrections between sessions.

How much can I use it?

Each account gets 40 agent turns a day; dragging, editing and exporting are unlimited.

Can I take the results with me?

The insight report exports as a Markdown file you can paste anywhere.

Who built it?

A solo builder working with Claude Code, during the Agent-Native Hackathon by Builder.io in November 2026.
